Orquestación: cron y Airflow

Hoja de referencia rápida: de lo simple a lo complejo, y las cuatro preguntas para diseñar un flujo programado.

Automatizar vs. orquestar

Automatizar = que una tarea corra sola. Orquestar = que varias tareas corran en orden, con dependencias, reintentos y avisos.

HerramientaComplejidadDependenciasInterfaz visualCuándo usarla
CronBajaNoNoTareas simples por horario
Programador de nubeBajaLimitadasParcialTareas simples en la nube
Apache AirflowMedia-altaSí (DAGs)SíFlujos complejos con monitoreo y alertas

Idea para la pizarra: para una tarea suelta, cron alcanza; para flujos complejos con aviso de fallas, Airflow.

Las cuatro preguntas del flujo

1. Frecuencia: ¿cada cuánto corre?  ·  2. Dependencias: ¿qué tarea espera a cuál?  ·  3. Si falla: ¿se reintenta? ¿se avisa? ¿se detiene todo?  ·  4. Trazabilidad: ¿dónde queda registrado qué corrió, cuándo y con qué resultado?

Ejemplo de cron: 0 6 * * 1 → todos los lunes a las 6:00. Fuente: documentación oficial de Apache Airflow (airflow.apache.org/docs).
