Herramientas de ingesta

Hoja de referencia rápida: conectores, scripts y APIs, y cuándo conviene cada familia.

Las tres familias

El método es el cómo y cuándo (batch o streaming); la herramienta es el con qué. Tres familias cubren casi todo:

Herramienta¿Qué es?¿Cuándo usarla?¿Requiere programar?
ConectorPieza hecha para una fuente/destinoFuentes conocidas y repetidasNo (configuración)
ScriptCódigo propioCasos a medida o transformacionesSí
APIPuerta de acceso estandarizadaCuando el sistema la ofreceUn poco (llamadas)

Para llevar: la mayoría empieza con archivos y scripts, y agrega conectores y APIs cuando la ingesta se vuelve repetida y crítica.

Casos que suelen aparecer

CasoHerramientaPor qué
Traer datos de una hoja de cálculo compartida a un almacénConectorFuente conocida; se configura sin código
