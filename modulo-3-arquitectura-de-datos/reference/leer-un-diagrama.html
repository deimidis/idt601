Referencia · Bloque 3 — Arquitectura de Datos

Leer un diagrama de arquitectura

Hoja de referencia rápida: cinco preguntas que permiten entender cualquier esquema, sin conocer la tecnología.

El procedimiento

Recorre el diagrama respondiendo estas preguntas en orden. Si puedes responderlas todas, entendiste la arquitectura.

PreguntaQué buscar
¿Dónde nacen los datos?Fuentes: sistemas, formularios, sensores.
¿Dónde se guardan?Almacenamiento: base operacional, data warehouse, data lake.
¿Qué los transforma?Procesamiento: procesos por lotes o en tiempo real.
¿Dónde está su definición?Catálogo: diccionario de datos, metadatos.
¿Quién controla el acceso?Gobernanza: dueños del dato, reglas, permisos.

Clave: con estas cinco preguntas se puede entender cualquier diagrama de arquitectura, sin conocer la tecnología. Si el catálogo o la gobernanza no aparecen, el diagrama está incompleto.

Para llevar

Fuentes → ¿de dónde?  ·  Almacenamiento → ¿dónde?  ·  Procesamiento → ¿cómo?  ·  Catálogo → ¿qué es?  ·  Gobernanza → ¿quién?

Fuentes: Kleppmann, Diseño de aplicaciones con uso intensivo en datos; Curto, Fundamentos de big data (UOC).
