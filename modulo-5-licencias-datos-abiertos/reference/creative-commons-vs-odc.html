Referencia · Bloque 5 — Licencias de Datos y Datos Abiertos

Creative Commons vs. Open Data Commons

Hoja de referencia rápida: las dos familias de licencias abiertas y sus equivalencias.

Dos familias, un mismo espíritu

Creative Commons (CC) nació para obras creativas y se usa mucho en documentos. Open Data Commons (ODC) está pensado específicamente para bases de datos. Las condiciones se corresponden una a una.

Creative CommonsOpen Data CommonsCondición
CC0ODC PDDLNinguna (dominio público).
CC BYODC-ByAtribución.
CC BY-SAODbLAtribución + compartir igual.

Cuál elegir: para una base de datos, ODC es técnicamente más adecuada; para una obra creativa (texto, imagen), CC. En ambos casos, las variantes con "no comercial" o "solo educativo" dejan de ser abiertas.

Para llevar

CC0 / PDDL → todo libre.  ·  CC BY / ODC-By → con atribución.  ·  CC BY-SA / ODbL → atribución + compartir igual.  ·  NC / educativo → no abierta.

Fuentes: creativecommons.org · opendatacommons.org · opendefinition.org.
