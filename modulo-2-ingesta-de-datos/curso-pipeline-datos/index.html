Antes de empezar

  1. Necesitás una cuenta gratuita en NocoDB Cloud y una tabla destino.
  2. Generá un API token (Account Settings → Tokens) y configurá la tabla según la guía.
  3. En Colab, guardá el token como Secret NOCODB_TOKEN (no lo pegues en el código).
