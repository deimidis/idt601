## Qué permite

Puedes **compartir, crear y adaptar** la base de datos, y **usarla con cualquier propósito**,
incluido el comercial. Está pensada para **bases de datos** (no para obras creativas, para las que se
usa Creative Commons).

## Condición

**Atribución.** Debes citar la fuente de la base de datos, incluir el aviso de copyright aplicable y
enlazar la licencia. Si modificas la base, debes indicarlo.

## En una frase

«Compartir y adaptar la base, con la condición de atribuir.»
