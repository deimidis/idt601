# Módulo 3 — Arquitectura de Datos (paquete docente)

Materiales de la **Unidad/Bloque 3 — Arquitectura de Datos** del módulo *Ingeniería de Datos
(IDT 601)*, Diplomado en Data Driven AI (EGPP 2026), organizados para el/la docente.

**Sesiones:** 4 y 5 · cada una sostiene **~180 min (3 horas)**.

## Contenido

| Archivo | Qué es |
|---|---|

| `GLOSSARY.md` | Lenguaje canónico de arquitectura (17 términos). |
| `RESOURCES.md` | Fuentes de confianza y gaps. |
| `03_Arquitectura_de_Datos.md` | Documento explicativo de la unidad (lectura base). |
| `Sesion_04_*.md`, `Sesion_05_*.md` | Planes de sesión (cronograma de 180 min, dinámicas, evaluación). |
| `presentacion_sesion4.(md/html)`, `presentacion_sesion5.(md/html)` | Presentaciones reveal (fuente `.md` + render `.html`). |
| `deck-sesion-04.html`, `deck-sesion-05.html` | Decks de participante, autocontenidos. |
| `notas-sesion-04.md`, `notas-sesion-05.md` | Guion del orador por diapositiva. |

## Cómo se mantiene

- Esta carpeta es una **copia de trabajo** de los materiales de la raíz del proyecto. La raíz
  **no se actualiza sola**: si se cambia un material en la raíz, hay que volver a copiarlo aquí.
- Las presentaciones reveal usan **reveal.js** desde `/home/deimidis/Proyectos/Presentaciones Revealjs`
  y el tema local `assets/theme-egpp.css`. Si esa carpeta no está disponible, usar el deck
  autocontenido (`deck-sesion-0N.html`), que funciona sin dependencias.
- Los talleres usan los esquemas SVG de `assets/` (`esquema-arquitectura-sin-etiquetas.svg` para los
  equipos y `esquema-arquitectura-resuelto.svg` para el docente).
- Esta carpeta se publica en el sitio estático `../idt601/modulo-3-arquitectura-de-datos/`.
- Pendiente (fase posterior): **banco de preguntas** para Moodle.
