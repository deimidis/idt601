# Datos — Recursos (Bloque 1, IDT 601)

Fuentes de confianza para preparar y dictar el Bloque 1. El conocimiento de las
lecciones se extrae de aquí, no de la memoria del agente.

## Knowledge

- [Libro: _Big Data: Análisis de grandes volúmenes de datos en organizaciones_, Luis Joyanes Aguilar (Alfaomega, 2013)](https://books.google.es/books?id=1GywDAAAQBAJ)
  Cubre tipos de datos (estructurados, no estructurados, semiestructurados), fuentes y tecnologías. Usar para: fundamentos de tipos de datos y ejemplos.
- [Libro: _Ciencia de Datos: Un enfoque práctico de tecnologías, herramientas y aplicaciones_, Luis Joyanes Aguilar (Alfaomega, 2024)](https://biblioteca.cuaed.unam.mx/img/alerta/Ciencia-de-datos-Lluis-Joyanes.pdf)
  Taxonomías de datos, analítica y calidad. Usar para: definiciones actualizadas y contexto amplio.
- [Material abierto: _Fundamentos de big data_, Josep Curto (FUOC/UOC)](https://openaccess.uoc.edu/server/api/core/bitstreams/4efc24a4-9563-4a0b-97d8-b790954ba50d/content)
  Texto abierto y gratuito en español. Usar para: fuente primaria citable sobre big data y tipos de datos.
- [Guía: _Open Data Handbook_, Open Knowledge Foundation](https://opendatahandbook.org/guide/es/)
  Conceptos de datos abiertos y su tratamiento. Usar para: contexto de apertura, formatos y reutilización.
- [Marco: _DAMA-DMBOK_, DAMA International](https://www.dama.org/)
  Referencia canónica de gestión y calidad de datos. Usar para: dimensiones de calidad. Nota: en inglés.
- [Norma: ISO/IEC 25012 — Modelo de calidad de datos](https://www.iso.org/standard/35736.html)
  Estándar que define características de calidad de datos (exactitud, completitud, consistencia, actualidad, entre otras). Usar para: respaldar las dimensiones con una norma. Nota: original en inglés; existe versión UNE en español.
