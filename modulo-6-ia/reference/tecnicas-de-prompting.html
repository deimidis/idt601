Técnicas de prompting

Hoja de referencia rápida: las cuatro técnicas para escribir prompts útiles y el ciclo para mejorarlos.

Las cuatro técnicas

Un prompt es la instrucción que le damos al modelo. Estas cuatro técnicas mejoran la respuesta y se pueden combinar; no es obligatorio usarlas todas.

TécnicaQué esEjemplo breve
ClaridadPedido específico: qué, formato, extensión y tono."En 5 líneas, tono formal…"
ContextoAntecedentes de quién pide y para qué."Soy funcionario municipal…"
Ejemplos (few-shot)Mostrar uno o dos ejemplos del resultado esperado."Seguí este modelo: 'Se informa…'"
RolPedir que asuma un papel para ajustar la voz."Actuá como asesor de transparencia…"

Por qué importa: el modelo genera según el contexto que recibe. Un pedido vago deja que el modelo adivine; un pedido claro y contextualizado reduce la adivinanza y la respuesta se vuelve reutilizable.

De vago a preciso

Vago: "háblame de impuestos"  →  Preciso: "explicá en 5 líneas, en tono formal, y para un funcionario municipal, qué es el impuesto predial".

El ciclo para mejorar

La primera respuesta es un borrador. Se itera: pedir → revisar → verificar → re-pedir.

Re-pedidos útiles: "resumilo en tres viñetas" · "reescribilo en lenguaje más sencillo" · "cambiá el tono a más formal" · "dejá solo lo respaldado y marcá lo dudoso como 'a verificar'".

Para llevar

Claridad → qué, formato, extensión, tono.  ·  Contexto → quién y para qué.  ·  Ejemplos → mostrar el resultado.  ·  Rol → asumir un papel.  ·  Iterar → pedir, revisar, verificar y re-pedir.

Fuente: OpenAI, Buenas prácticas para la ingeniería de prompts; Microsoft Learn, IA generativa para principiantes.
